## Prioridade 1 — Fazer agora, grátis (base + certificado oficial da Anthropic)

### Anthropic Academy
A própria empresa criadora do Claude oferece cursos gratuitos com certificado oficial.
Nenhum outro lugar ensina Claude melhor do que eles — e o certificado tem peso crescente no mercado.

| Recurso | Tipo | Custo |
|---|---|---|
| [Claude 101](https://anthropic.com/learn) | Curso base — o que é Claude e como usar | Grátis | ✅ Certificado obtido |
| [Claude Code 101](https://anthropic.com/learn) | Para desenvolvedores — uso prático | Grátis | ✅ Certificado obtido |
| [Build with Claude](https://anthropic.com/learn) | Aplicações reais com API | Grátis | |
| [AI Fluency for Builders](https://anthropic.com/learn) | IA aplicada ao trabalho de dev | Grátis | |

**Meta prática:** completar os 4 cursos acima e emitir os certificados para colocar no LinkedIn.

## Prioridade 4 — Meta de 3 meses (maior peso em empresa grande)

### Microsoft Azure AI Fundamentals — AI-900
Aparece em vagas de empresas médias e grandes no Brasil.
**É esse que vai em destaque no currículo** — Microsoft no certificado é universalmente reconhecido.

| Recurso | Tipo | Custo |
|---|---|---|
| [Microsoft Learn — AI-900 (gratuito)](https://learn.microsoft.com/pt-br/credentials/certifications/azure-ai-fundamentals/) | Estudo oficial em PT-BR | Grátis |
| [AI-900 — Simulados e prep (MeasureUp)](https://www.measureup.com/) | Simulados | ~R$ 200 |
| [Prova oficial via Pearson VUE](https://home.pearsonvue.com/microsoft) | Exame presencial ou online | ~R$ 900 |

**Meta prática:** estudar pelo Microsoft Learn (gratuito, em português), fazer simulados e agendar a prova.

## O que NÃO vale para IA no currículo

- **4Linux** — ótima escola, mas a reputação deles é em Linux/DevOps/infra (LPIC). Não são referência em IA.
- Cursos genéricos de Udemy sem nome reconhecido — não impressionam empresas médias/grandes.
- Certificados de plataformas desconhecidas — volume não substitui peso do nome.

```
Semana 1-2  → Anthropic Academy (Claude 101, Claude Code 101)     — grátis, começa hoje

Mês 2       → Google AI Essentials ou Samsung Ocean (PT-BR)       — grátis ou ~R$250
Mês 3       → Estudo AI-900 pelo Microsoft Learn                  — grátis
Mês 3       → Prova AI-900 (Pearson VUE)                          — ~R$900, maior peso
```
